# How to use embed feature in the portals?

With Embeds, you can display content from other services on the portal pages, such as:

-   video from YouTube
-   an analytical report from PowerBI
-   a booking form from Calendly

You can add Embeds through the Customizer or through the Fusebase page editor.

## Adding an Embed via the Customizer [#](#b217255344_978)

-   Go to the Customizer for the portal.
-   Navigate to your page or create a new one.
-   Select Custom Embed from the Add Block menu:

![](https://thefusebase.com/wp-content/uploads/2023/11/Adding-an-Embed-via-the-Customizer.png)

-   Enter the widget name and embed code (e.g. Youtube code on video or code from PowerBI):

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20526%20630'%3E%3C/svg%3E)

-   Click the Add button:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20518%20548'%3E%3C/svg%3E)

-   After saving, the Embed will appear on the portal page:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20441'%3E%3C/svg%3E)

-   When you are satisfied with everything, save the changes by clicking Publish:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20935%20632'%3E%3C/svg%3E)

## Adding an Embed via the Fusebase page editor [#](#b217255344_2313)

-   Go to the web version
-   Open or create the desired page in the client:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20486'%3E%3C/svg%3E)

-   Click on the desired location in the editor and select Integrations from the list of options:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20576'%3E%3C/svg%3E)

-   Enter the code or link to the service in the input field:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20557'%3E%3C/svg%3E)

-   The embedded content will be successfully displayed on the page:

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20527'%3E%3C/svg%3E)

It is important to note that in this case, you do not need to publish the changes—they are published automatically.
