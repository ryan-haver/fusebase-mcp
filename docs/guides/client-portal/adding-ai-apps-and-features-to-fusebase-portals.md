# Adding AI Apps and Features to FuseBase Portals

In FuseBase, you can create apps of any complexity for your own use cases as well as for your clients. For example, these can include various dashboards, forms, reports, widgets, and more. You can read more about apps and how to create them here: [https://thefusebase.com/guides/fusebase-vibe-code/fusebase-apps-quick-guide/](https://thefusebase.com/guides/fusebase-vibe-code/fusebase-apps-quick-guide/)

In this guide, we will explain how you can add ready-made features to your portals.

1) To get started, go to the desired portal page in the customizer and click Add block.

![](https://thefusebase.com/wp-content/uploads/2026/03/image-23-1024x546.png)

2) Click on Fusebase App.

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20551'%3E%3C/svg%3E)

3) Next, select the desired app and the feature you want to add to the portal page.

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20516'%3E%3C/svg%3E)

If you wish, you can make the feature public right away, allowing even anonymous portal visitors to access it.

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20484'%3E%3C/svg%3E)

Next, click Publish to make the feature available on the portal.
