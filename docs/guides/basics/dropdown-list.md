# Dropdown List

With the Dropdown object, you can create a sheet with a list of options to choose from, depending on your needs.

## Creating a List [#](#0-toc-title)

You can create a list through the objects menu – **Dropdown List**.

![Creating a List. Image by FuseBase](https://thefusebase.com/wp-content/uploads/2023/03/preview-5.png)

Next, you need to make a list of options that will be on the sheet. There can be several options in the list, but only one can be chosen.

![Dropdown list. Gif by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20903%20677'%3E%3C/svg%3E)

To select another option from the list, click on **the** **list item**.

![List Item. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20418%20162'%3E%3C/svg%3E)

Choose the desired option from the list.

![The Desired Option. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20462%20244'%3E%3C/svg%3E)

## Changing List Items (renaming and color changing) [#](#1-toc-title)

You can change individual list items, such as renaming or changing color. You can do this via **the list item menu**.

![Individual List Items. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20471%20218'%3E%3C/svg%3E)

You can rename the option name or change its color.

![The Option Name. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20613%20336'%3E%3C/svg%3E)

You can also change the style of the list.

![The Style of the List. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20544%20297'%3E%3C/svg%3E)

## Deleting a List Item [#](#2-toc-title)

To delete a list item, you need to select **the Delete option** in the item menu.

![Deleting the List Item. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20547%20318'%3E%3C/svg%3E)

## Deleting the List [#](#3-toc-title)

You can delete the entire list just like any other object from the object menu.

![Deleting the List. Image by FuseBase](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20831%20386'%3E%3C/svg%3E)
