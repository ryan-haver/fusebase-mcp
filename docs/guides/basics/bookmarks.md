The bookmark in [FuseBase](https://thefusebase.com/) is a special card where, in addition to a link, there is a title, small description and preview picture of the website shown.

## How to add a bookmark?

There are several ways to add a bookmark.

-   Add a link through **Paste** or **Ctrl** + **V**.
-   Select **Bookmark**.

![How to add a bookmark?](/hosting-assets/legacy/thefusebase/box/attachment/4776269/41po6qax4cdikfie0lgz/zh4Po3WD4Pofmlee/canva.gif)

-   Click on the object menu and select **Bookmark** or use the hotkey **cmd/ctrl** \+ **⌥/alt** + **b**.
    -   Paste or type the URL.
    -   Press **Enter**.

![How to add a bookmark?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/MbrugXdQfhrhJSuW/bookmark 2.gif)

In FuseBase, you can use one of three modes of bookmark displaying: **Card** , **Tile** and **Cover**

In Tile mode, the link and title of the website are displayed.

You can use display mode Cover to show the preview picture in large size. This mode helps you not to get lost in multiple columns in your pages. To turn on Cover mode, go to the bookmark menu and choose View as.

![This mode helps you not to get lost in multiple columns in your pages. ](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/mxHE00GRHbo4ekpI/Group 44.png)

Cover mode displays the preview and title in cover format.

![Cover mode displays the preview and title in cover format.](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/86FDf0BpBk3iG5Cm/Group 51 (1).png)

To change the display mode, click on the bookmark menu.

![To change the display mode, click on the bookmark menu.](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/tvBIMFHXuOSN0xu5/Group 52 (1).png)

### Can I change the link, title or description of the link?

Yes, just click on the bookmark menu and select **Edit**.

Next, change what you need and click **Done** or press **Enter**.

![Can I change the link, title or description of the link?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/hFQYthaeBBK4NEI8/Group 46.png)

### Can a regular link be turned into a bookmark and vice versa?

Yes, to turn a regular link into a bookmark, click on **Convert to** in the link menu and select **Bookmark**. Also, you can turn a bookmark into a regular link. To do this, in the bookmark menu, select **Convert to** – **Link**.

![Can a regular link be turned into a bookmark and vice versa?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/dwATwzWt8fuSB8uD/Group 47.png)

### Can I change the preview picture?

You can upload your own images that will be displayed like the bookmarks preview. To do this, open the tab menu and click on Change preview.

Click on the bookmark menu and select **Change preview** Next, choose a new picture.

![Can I change the preview picture?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/bpkxXS7ba3yKXOCZ/Group 48.png)

You can also upload your own picture for preview.

-   Click on **Upload new.**
-   Upload a picture.

### How can I delete a bookmark?

Click on the bookmark menu and select **Delete**.

![How can I delete a bookmark?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/aR7souOz68qVnLS8/Group 49.png)

### How to move a bookmark to another place in the page?

Click on the bookmark menu, hold the mouse button and move the bookmark to the desired place.

![How to move a bookmark to another place in the page?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/VfNS4KPddlO2XSSn/drag (1).gif)

### How to duplicate a bookmark?

Click on the bookmark menu and select **Duplicate**.

![How to duplicate a bookmark?](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/RnW01G5osQfbJ0Nk/Group 50.png)

## Start Pages

Using bookmarks, you can create thematic pages with a list of links.

For example, create a News page and add links to news pages. You’ll have a convenient start page, and you can simply go to the News page to find the links you need.

![Using bookmarks, you can create thematic pages with a list of links.](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/GHQdXsC9x8y8RI7t/Group 57.png)

## How to set as Start Page or New Tab Page

-   Get the **public link** for a page or folder.

![How to set as Start Page or New Tab Page](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/LPokh5mBHuxmvHEH/public_note (2).gif)

![How to set as Start Page or New Tab Page](/hosting-assets/legacy/thefusebase/box/attachment/4776269/41po6qax4cdikfie0lgz/c4Lah9F4Umlqmwfm/public_folder.gif)

-   Set a **password** as needed.

![How to set as Start Page or New Tab Page](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/lI6dGg5W3TCYXK1x/Group 14 (6).png)

-   Go to **browser settings**, and find the section **On startup**
-   Select **Open a specific page or set of pages**.
-   **Add a new page.**

![How to set as Start Page or New Tab Page](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/jgJYREYh6QUEk2K2/Group 15 (7).png)

![How to set as Start Page or New Tab Page](https://thefusebase.com/box/attachment/4776269/41po6qax4cdikfie0lgz/6NEs5QdugtDxH9QZ/Group 16 (7).png)
