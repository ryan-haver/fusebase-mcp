# Task Board Guide

In [FuseBase](https://thefusebase.com/), you can create not only the usual task lists but also full-fledged Kanban Boards using the Task Board object. You can create an object through the menu of objects in the editor –

![You can create an object through the menu of objects in the editor](https://thefusebase.com/wp-content/uploads/2023/01/Task_Board_1.png)

By default, two columns are created in the board, but you can create new ones through the Add column option –

![By default, two columns are created in the board, but you can create new ones through the Add column option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20719%20236'%3E%3C/svg%3E)

## How do I rename the board? [#](#0-toc-title)

By default, the board has a standard name, but you can rename it. To do this, simply click on the name of the board and specify the desired name –

![By default, the board has a standard name, but you can rename it. To do this, simply click on the name of the board and specify the desired name](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20698%20239'%3E%3C/svg%3E)

## How do I rename a column name? [#](#1-toc-title)

Hover over the column name and click on the edit icon –

![Hover over the column name and click on the edit icon](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20707%20244'%3E%3C/svg%3E)

Then enter a new column name and press Enter to confirm –

![Then enter a new column name and press Enter to confirm](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20707%20244'%3E%3C/svg%3E)

## How do I add labels/descriptions/date, etc. to a task? [#](#2-toc-title)

Click the name of the task to open it in a detailed view. Next, you can add a description, labels, date, etc. to the task –

![Click the name of the task to open it in a detailed view. Next, you can add a description, labels, date, etc. to the task](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20559'%3E%3C/svg%3E)

## How do I delete a column? [#](#3-toc-title)

Click on the column’s menu icon and select Delete –

![Click on the column's menu icon and select Delete](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20714%20337'%3E%3C/svg%3E)

## How can I delete a task? [#](#4-toc-title)

Open the task in detail view and select Delete task in the task menu –

![Open the task in detail view and select Delete task in the task menu](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20433'%3E%3C/svg%3E)

## Can I move columns and tasks within the board? [#](#5-toc-title)

Yes, of course. You can:

-   Swap columns
-   Reorder tasks in columns
-   Transfer tasks between columns

To do this, click on a column or task and keep the mouse button pressed while doing the necessary action –

![](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201024%20512'%3E%3C/svg%3E)

## Is it possible to convert the board column to a regular task list? [#](#6-toc-title)

Yes, you need to select Convert to the task list in the column menu to do this –

![Yes, you need to select Convert to the task list in the column menu to do this](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20984%20326'%3E%3C/svg%3E)
