In FuseBase, you can add a progress bar not only as a separate type of column in the table, but also as a separate object. For example, you can use it to track the progress of some tasks or actions.

## How to Add a Progress Bar

You can add a progress bar through the menu of objects. You can add an object to the beginning of the line or inside the text.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/03/image-18.png)

By default, the progress bar is at zero.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/03/image-19.png)

But you can move the value of progress in one direction or another.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/03/preview.gif)

## How to Remove the Progress Bar

You can delete progress the same way as any other object – through the block menu.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/03/image-21.png)
