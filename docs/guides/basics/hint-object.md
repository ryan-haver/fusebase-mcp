You can use a **Hint object** in the editor. The object is ideal if you need to specifically highlight text, such as a notification, warning, or hint. Besides the text, you can also paste an icon that can add emotion to the message. Add a hint on the object menu.

## How to add a hint?

-   Click on the object menu and select **Hint** or use the hotkey **cmd/ctrl** + **⌥/alt** \+ u.

![How to add a hint?](https://thefusebase.com/box/attachment/5452817/8bwvsm6mp4w5pggfgx3y/ySs9MgOslxVK2hRu/Group 191 (1).png)

## How to change the hint icon?

-   Click on the **icon**.
-   Select **another icon**.

![How to change the hint icon?](https://thefusebase.com/box/attachment/5452817/8bwvsm6mp4w5pggfgx3y/EIBItBCcOlQytkor/Group 192 (1).png)

## How to add a border?

-   Click on the **menu**.
-   Select **Border Color**.

![How to add a border?](https://thefusebase.com/box/attachment/5452817/8bwvsm6mp4w5pggfgx3y/VtgqieYnnG2Khtr2/Group 267.png)

## How to add a colored line?

-   Click on the **menu**.
-   Select **Line color.**

![How to add a colored line?](https://thefusebase.com/box/attachment/5452817/8bwvsm6mp4w5pggfgx3y/TF8xAu1bAsDq4VVI/Group 266.png)
