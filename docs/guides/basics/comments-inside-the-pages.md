In FuseBase, you can comment on and discuss text blocks, images, files, tables and more. In the comments, you can use mentions to notify other workspace participants. At the end of the discussion, you can mark the thread as resolved or delete it.

## Adding comments

To add a comment in the web or desktop application, follow these steps.

-   Click on the three dots next to the desired block.
-   Select **Comment**.
-   In the pop-up that appears, type your comment and press **Enter**.

## Inline comments

In FuseBase, you can add inline comments to the selected text.

-   Highlight the desired text (a word/sentence or multiple blocks of text).
-   Click on the comment icon.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-28.png)

-   Add comment.
-   A thread with an inline comment will be created.

After creating a comment, you will see the commented text is highlighted and the counter icon next to the commented block will appear. The counter defines the number of comments inside the thread.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-29.png)

## View comments

To view a comment for a desired block, tap on the comment icon, which can be found to the right of the block.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-30.png)

### Adding replies to comments

To add a reply, you need to:

-   Go to the desired thread.
-   Tap on the desired comment.
-   Select the reply icon.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Frame-2147207152-17-1024x409.png)

-   Write the comment in the input field and press **Enter**.

## Deleting a comment and deleting the entire thread

You can delete both an individual response and the entire comment thread in a block.

### Deleting a comment

To delete a comment inside a thread:

-   Open a thread.
-   Click on the desired comment.
-   Select the trash icon.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Frame-2147207152-22.png)

### Deleting the entire thread

To delete the entire thread, do the following.

-   Open the thread.
-   Click on the **Delete** in thread’s menu.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Frame-2147207152-19.png)

## Editing a comment

You can also edit your comment at any time (it will be marked as edited). To do this:

-   Open a thread.
-   Click on the desired comment.
-   Select the Edit icon.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Frame-2147207152-21.png)

## Resolve thread

If the issue in the thread is fixed, then you can mark it as resolved.

-   Open the thread.
-   Select the checkmark (resolved icon) at the top of the pop-up.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Frame-2147207152-18.png)

After resolving a thread, you will not see it in the list of threads.

To see the resolved threads, open the page and enable the **Show resolved comments** toggle in the page’s menu.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/image-36-1-1.png)

## Adding files to comments

In addition to text, you can add files to your comments. For example, they can be screenshots with a description of the problem or an archive with a design.

### Adding a file

To add a file, click on **the attachment icon** in the comment input.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-6.png)

Next, select the desired file and wait for it to load. It will be displayed on the comment card.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-7.png)

Click on **the submit comment button** to add it to the thread.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-8.png)

🚩 You can also paste a picture into a comment via the **ctrl+v hotkey**.

### File download

Click on **the file name** or on **Download** to download the file.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-9.png)

### Deleting a file

If you want to delete a file, click on **Delete** in the file menu (displayed when you hover over the file).

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2023/08/image-10.png)
