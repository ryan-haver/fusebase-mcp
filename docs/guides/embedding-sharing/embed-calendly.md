## How do I copy an embed code from Calendly?

-   Log in to your **Calendly** account or create a new account.
-   Select event and click on **Share**.

![How do I copy an embed code from Calendly?](https://thefusebase.com/box/attachment/5585054/ui3yb0k8urztcxk6wxr2/LE0SUsUt41FIYDmU/Group 236.png)

-   Go to **Add to website section**.
-   Select Embed inline.

![Select Embed inline.](https://thefusebase.com/box/attachment/5585054/ui3yb0k8urztcxk6wxr2/qy3gL4k1L8Gk00Tn/Group 237.png)

-   Copy the code. 

![Copy the code. ](https://thefusebase.com/box/attachment/5585054/ui3yb0k8urztcxk6wxr2/16HbWzLbw9tFcArq/Group 238.png)

## Adding Calendly embed to FuseBase

-   Open [FuseBase](https://thefusebase.com/).
-   Click on the arrow and select **Embed** or **cmd/ctrl** + **⌥/alt** + **m**.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Group-239-1024x607.png)

-   Add the code using **Cmd/Ctrl**+**V**.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Group-242-1024x687.png)

### Resize Embeds

-   Drag the upper-right corner and **resize** (all proportions will be preserved).

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Group-240-1024x687.png)

-   For free resizing, hold the **ALT key** and start resizing using the bottom-right chip.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Group-243-1-1024x687.png)

**Note: To return the embed to its original position, use the hotkey Ctrl + Z, or click on the three dots and select Undo.**
