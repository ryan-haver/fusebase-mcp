## How do I copy an embed link from Miro?

-   Click on the **Export** this board icon.

![How do I copy an embed link from Miro?](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/2bsLS7naXWSOKD2W/Group 134.png)

-   Select **Embed**.

![How do I copy an embed link from Miro?](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/S8998ETXNM0bQotI/Group 133.png)

-   Click on **Share Settings** and select the desired permissions.

![Click on Share Settings and select the desired permissions.](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/s3wd3tiSabNJprX2/Group 132.png)

![Click on Share Settings and select the desired permissions.](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/FkFwg04SkxP7OtaY/Group 131 (1).png)

-   Select **Copy board link** and the link will be successfully copied.

![Select Copy board link and the link will be successfully copied.](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/aDoEBaxJ4BNYkuWN/Group 130.png)

## Adding Miro embed to FuseBase

-   Open [FuseBase](https://thefusebase.com/).
-   Paste the link into the page by using **Cmd/Ctrl**+**V**, or by right-clicking and selecting **Paste**.
-   Select **Embed**.

![Adding Miro embed to Nimbus Note](/hosting-assets/legacy/thefusebase/box/attachment/5004037/bm25wapvb55t3o9qcllc/GHcZnnWo0FnoZndv/miro7.gif)

### Resize Embeds

-   Drag the upper-right corner and resize (all proportions will be preserved).

![Drag the upper-right corner and resize (all proportions will be preserved).](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/I582pNpJsfrTT0Fn/Group 129.png)

-   For free resizing, hold the ALT key and change the size using the bottom-right chip.

![For free resizing, hold the ALT key and change the size using the bottom-right chip.](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/B7hGEVFEP00sDLO9/Group 128.png)

**Note: To return the embed to its original position, use the hotkey Ctrl + Z, or click the three dots and select Undo.**

![To return the embed to its original position, use the hotkey Ctrl + Z, or click the three dots and select Undo.](https://thefusebase.com/box/attachment/5004037/bm25wapvb55t3o9qcllc/BaUrhTh56mBkmr2Y/Group 127.png)
