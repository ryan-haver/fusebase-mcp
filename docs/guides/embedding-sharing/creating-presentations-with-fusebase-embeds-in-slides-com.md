# Creating presentations with FuseBase embeds in Slides.com

With Slides.com, you can create a presentation with FuseBase public pages.

Guide details

Published

September 1, 2022

Read time

1 min read

Category

Embedding & Sharing

In this guide

This guide is a short walkthrough.

With Slides.com, you can create a presentation with FuseBase public pages.

-   Log into your [Slides.com](https://slides.com/) account (or create a new account).
-   Create a new presentation or open an existing one.
-   Click on **Add Iframe**.

![With Slides.com, you can create a presentation with Nimbus Note public pages.](https://thefusebase.com/box/attachment/5302510/4wvbezfdka0z3pohv926/Ae5wlAK40pOXgkWB/Group 208.png)

-   Open the desired FuseBase page and make it **public**.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Frame-2147207154-1-1024x704.png)

-   In the public link dialog, select **Embed** and **copy** the iFrame code.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Group-210.png)

-   **Add the copied code** to Slides.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Frame-2147207154-2-1024x553.png)

For the frame that appears, you can also change the size.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Frame-2147207154-3-1024x705.png)

Next, you can add embeds to other slides, and then share your presentation.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/09/Frame-2147207154-4-1024x543.png)
