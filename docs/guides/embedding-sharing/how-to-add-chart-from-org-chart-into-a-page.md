# How to add chart from Org chart into a page in FuseBase

![How to add chart from Org chart into a page in Nimbus](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

## How to copy the sharable link in Org Chart [#](#b30790726_529)

-   Open [https://orgchart.timeisltd.com/charts](https://orgchart.timeisltd.com/charts).
-   Click on **Share**.

![How to copy the sharable link in Org Chart](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

-   Select **Get sharable link**.
-   Under the Link to Org Chart section, select Copy.

![Under the Link to Org Chart section, select Copy.](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

## How to add chart from Org chart into a page in FuseBase [#](#b30790726_842)

-   Open [FuseBase](https://thefusebase.com/).
-   Insert the link through **right-click** or **ctrl**+**v**.
-   Select **Embed**.

![How to add chart from Org chart into a page in Nimbus](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

### Resize Embeds [#](#b2916505007_0)

-   Drag the upper-right corner and **resize** (all proportions will be preserved).

![Drag the upper-right corner and resize (all proportions will be preserved).](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

-   For free resizing, hold the **ALT** key and change the size using the bottom-right chip.

![For free resizing, hold the ALT key and change the size using the bottom-right chip.](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%200%200'%3E%3C/svg%3E)

**Note: To return the embed to its original position, use the hotkey Ctrl + Z, or click the three dots and select Undo.**
