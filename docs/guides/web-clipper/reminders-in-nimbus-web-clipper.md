### How to set a reminder in clipper?

1) Click on the reminder icon.

![How to set a reminder in clipper?](/hosting-assets/legacy/thefusebase/images/crem1.jpg)

2) Select a date and specify the time. Set the reminder to repeat if needed.

![Select a date and specify the time. Set the reminder to repeat if needed.](/hosting-assets/legacy/thefusebase/images/crem2.jpg)

3) Click Done.

### How to change a reminder?

Click the reminder icon and set new parameters.

### How to delete a reminder?

Click on the reminder icon and press Delete.

![How to delete a reminder?](/hosting-assets/legacy/thefusebase/images/crem4.jpg)
