## Code

To add a code to a page, do the following.

-   Click on the arrow in the editor to display **more items**.
-   Select **Code** or use the hotkey **cmd/ctrl** + **⌥/alt** + **c**.
-   Paste or type the code in the block that appears.

![To add a code to a page, do the following.](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Group-64.png)

**☝ Note: You can select the language you want at once. Just click on the block menu and select the desired language from the list.**

![You can select the language you want at once. Just click on the block menu and select the desired language from the list.](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Group-171-1.png)

### Theme

In [FuseBase](https://thefusebase.com/), you can choose a theme for the code that is perfect for daytime or nighttime use.

-   Click on the **menu**.
-   Choose the **desired theme**.

![In Nimbus Note, you can choose a theme for the code that is perfect for daytime or nighttime use.](https://thefusebase.com/box/attachment/4809958/nwstfilteyvx4qub7fsd/yyqcmdKa9jmwkqnY/Group 172 (1).png)

### Show/Hide line numbers

-   Click on the **menu**.
-   Select **Show/Hide line numbers**.

![Show/Hide line numbers](https://thefusebase.com/box/attachment/4809958/nwstfilteyvx4qub7fsd/icO5ybBa5avFGDpx/Group 173 (1).png)

## Inline code

In addition to Bold or Italic, FuseBase has other ways to highlight text, such as Inline code.

-   Select the desired text.
-   In the menu that appears, select the code icon or use the hotkey **cmd/ctrl** + **⌥/alt** + **e**.

![In addition to Bold or Italic, FuseBase has other ways to highlight text, such as Inline code.](/hosting-assets/legacy/thefusebase/wp-content/uploads/2022/08/Group-9-8-1024x609.png)

## Code highlights

-   Select text with Inline code.
-   Click on the palette to change the color of the text / marker or select a marker with a frame.
