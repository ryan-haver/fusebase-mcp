This guide is a short walkthrough.

You can disable the features in the web client that you do not need. For example, if you do not use automation or portals, you can hide them so they do not distract you.

This can be done via Organization settings -> Navigation.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2026/08/image-26-1024x549.png)

Next, simply disable the features you don’t need, and they will be hidden from the web client.

![](/hosting-assets/legacy/thefusebase/wp-content/uploads/2026/08/image-27-1024x549.png)

It’s important to note that this operates at the organization level – meaning if you disable Automation, that section will be hidden for all members of the organization.

Also keep in mind that these settings only hide items in the web client and do not affect their functionality. For example, if you already had automation flows, they will not be deleted if you hide Automation in the settings.
