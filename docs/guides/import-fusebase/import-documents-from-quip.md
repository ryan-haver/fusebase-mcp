## Export pages from Quip

-   Log in to your **Quip account**.
-   Open the document you want.
-   Select **HTML** from the Document – **Export** menu.

![Export pages from Quip](https://thefusebase.com/box/attachment/5533625/7of68nf4k6xhp6ywad8b/yeOPK2cvqSg6TULp/Group 210 (1).png)

-   Save the exported file.

## Import pages to Nimbus

![Import pages to Nimbus](https://thefusebase.com/box/attachment/5533625/7of68nf4k6xhp6ywad8b/UOgYvBRUk4PSwKNr/quip (2).gif)

-   Open [Nimbus Note](https://thefusebase.com/note/).
-   On the import menu, click on **Import from Quip**.

![Import pages to Nimbus](https://thefusebase.com/box/attachment/5533625/7of68nf4k6xhp6ywad8b/vmETA0Mof1CXqK5F/Group 208 (1).png)

![Import pages to Nimbus](https://thefusebase.com/box/attachment/5533625/7of68nf4k6xhp6ywad8b/88Ac8cyZvnCgKFFF/Group 209 (2).png)

-   Select the exported **HTML file**.
-   Wait for the import to finish.
