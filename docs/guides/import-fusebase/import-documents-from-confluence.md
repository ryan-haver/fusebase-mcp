## Export pages from Confluence

-   Export the desired documents to an HTML file. You can find detailed instructions here – [https://support.atlassian.com/confluence-cloud/docs/export-content-to-word-pdf-html-and-xml/](https://support.atlassian.com/confluence-cloud/docs/export-content-to-word-pdf-html-and-xml/)
-   Save the exported file.

## Import pages to Nimbus

![Import pages to Nimbus](/hosting-assets/legacy/thefusebase/box/attachment/5533631/ok5oyte7f3ld4kyd6w2n/MyR5bTzw5JfIJyAs/confluence_1.gif)

-   Open [Nimbus Note](https://thefusebase.com/note/).
-   In the import menu, click on **Import from Confluence**.

![Import pages to Nimbus](https://thefusebase.com/box/attachment/5533631/ok5oyte7f3ld4kyd6w2n/rSSQ7AX4ryGxHRqJ/Group 213 (1).png)

![Import pages to Nimbus](https://thefusebase.com/box/attachment/5533631/ok5oyte7f3ld4kyd6w2n/rFIWh7hOwVLOJUV0/Group 209 (2).png)

-   Select the exported **HTML file**.
-   Wait for the import to finish.
