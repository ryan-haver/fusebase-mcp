## How to add my own watermark to a video?

To get started, you can watch this video showing basic Watermark features.

1) Before recording a video, press Add your watermark.

![Before recording a video, press Add your watermark.](/hosting-assets/legacy/thefusebase/images/woterenv1.jpg)

2) You will be taken to the Watermark settings window, where you need to press Enable watermark.

![You will be taken to the Watermark settings window, where you need to press Enable watermark.](/hosting-assets/legacy/thefusebase/images/wateren2.jpg)

3) Select watermark type:  
– if you are using a picture, select “file”

![Select watermark type](/hosting-assets/legacy/thefusebase/images/wateren4.jpg)

– if you are using text, write the one you need, then choose font and color.

![Select watermark type](/hosting-assets/legacy/thefusebase/images/wateren3.jpg)

4) Specify the watermark location on the video.

![Specify the watermark location on the video.](/hosting-assets/legacy/thefusebase/images/wateren5.jpg)

Now watermarks will be added to all of your videos automatically.
